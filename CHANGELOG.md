# Changelog

All notable changes are documented via GitHub Releases and the Release Notes section in `README.md`.

## Policy

- Patch and minor changes: listed in GitHub Release auto-generated notes.
- Major changes: summarized in README Release Notes.
- Security fixes: coordinated via GitHub Security Advisories.

## Why No Detailed Changelog Here?

The action is small and version tags map directly to the built `dist/` artifact. Duplication across README, Releases, and a separate changelog would add maintenance overhead.

## Where To Look

- GitHub Releases page for per-version details.
- Tags (`git tag --list 'v*'`) for available versions.
- README for latest highlight summary.

## Example (Historical)

- v0.1.0: Initial humans.txt-only release with TEAM/THANKS/SITE sections.
