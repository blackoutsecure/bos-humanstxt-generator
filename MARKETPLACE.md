# Humans.txt Generator

Generate a humans.txt file from GitHub Actions inputs. Ideal for static sites that want to credit the people, tools, and standards behind the project.

## Highlights

- Humans.txt only; no sitemap/robots/security logic.
- Supports TEAM, THANKS, and SITE sections per humanstxt.org.
- Optional header comments and debug output.
